# 🧮 Calculadora Simples em Python

Uma calculadora interativa via terminal desenvolvida em Python. O projeto foi evoluindo para incluir tratamentos de erros avançados e validações de fluxo de repetição.

## ✨ Funcionalidades

- ➕ Operações matemáticas básicas: Soma, Subtração, Multiplicação e Divisão.
- 🔁 **Laço de Repetição (`while True`)**: Permite realizar múltiplas contas sem fechar o programa.
- 🛡️ **Tratamento de Erros (`try/except`)**: O programa não quebra se o usuário digitar letras ou caracteres inválidos no lugar de números.
- ⏹️ **Opção de Saída**: Pergunta ao usuário se ele deseja continuar ou encerrar o programa a cada operação.

## 🚀 Como executar o projeto

### Pré-requisitos
Você vai precisar apenas do **Python 3** instalado na sua máquina.

### Execução
1. Clone o repositório ou baixe o arquivo `index.py`.
2. Abra o terminal na pasta do arquivo e execute o comando:
   ```bash
   python index.py
   ```

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- Estruturas condicionais (`if`, `elif`, `else`)
- Manipulação de strings (`.upper()`)
- Tratamento de exceções (`ValueError`)
